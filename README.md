# Countdown Timer

A simple countdown timer built with **HTML, CSS and vanilla JavaScript**.

## Features
- Start and pause the countdown.
- Reset the timer.
- Choose a duration from 1 to 180 minutes.
- Responsive interface.

## Run locally
1. Clone or download this repository.
2. Open `index.html` in your browser.

No installation or build tools are required.

## Files
- `index.html` — timer interface
- `style.css` — layout and styling
- `script.js` — countdown logic

## What this project practises
Working with intervals, time calculations, and button events.
